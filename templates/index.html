📄 Comparar listado PDF (SAP)

      
    

    

      

        

          Sube el "Listado de Pedidos" simplificado que exporta SAP para un
          hotel (un PDF por hotel, una línea por pedido) — se comparan todos los números de
          pedido del listado contra los que ya están dados de alta aquí, para detectar compras
          hechas en SAP que se hayan quedado sin registrar en esta aplicación, y además se
          deduce el estado de entrega de cada pedido (Entregado / Entrega parcial / No
          entregado) comparando el importe del pedido con el importe recibido. Los proveedores
          marcados como no sujetos a seguimiento (Proveedores → ficha del
          proveedor — pensado para alimentación/bebida) se excluyen del todo del resultado.
        

        

          

            
            
          

          

            
            
          

        


        
        

          
          

            Cruza el importe ya recibido de cada pedido que SAP muestra como
            Entregado/Entrega parcial (arriba) con el importe de cada albarán de este segundo
            listado — al coincidir proveedor e importe, propone registrar en el pedido la fecha
            de tramitación, el número de entrada del albarán y el cambio de estado, para que los
            confirmes antes de aplicarlos.
